# PANDUAN SLIDE PRESENTASI

---

## 1. Berkas Presentasi yang Tersedia

1. **[`index.html`](./index.html) &mdash; Slide Presentasi Interaktif HTML (Direkomendasikan)**
   * Format slide modern yang dapat langsung dibuka di peramban apa pun (Google Chrome, Microsoft Edge, Firefox, Safari).
   * **Navigasi Keyboard:**
     * Tekan `ArrowRight` (Panah Kanan) atau `Spasi` untuk ke slide berikutnya.
     * Tekan `ArrowLeft` (Panah Kiri) untuk ke slide sebelumnya.
     * Tekan `F11` untuk mode Layar Penuh (*Fullscreen Presentation Mode*).
   * Dilengkapi indikator progress bar, counter slide, kartu ringkasan, diagram arsitektur, dan tabel hasil komparasi benchmark riil.

2. **[`SLIDES.md`](./SLIDES.md) &mdash; Format Presentasi Markdown (Marp Ready)**
   * Dapat diekspor menjadi PDF atau PowerPoint PPTX menggunakan ekstensi **Marp for VS Code** atau CLI Marp (`npx @marp-team/marp-cli SLIDES.md --pptx`).
   * Cocok untuk penyerahan berkas tugas dokumen presentasi terstruktur.
