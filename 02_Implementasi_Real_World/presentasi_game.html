POS 02 • BAGIAN 01 • PROBLEM STATEMENT

Kilas Balik: Inefisiensi Fatal Random Scheduling (Minggu 3)

Pada evaluasi tugas Minggu 3, Random Scheduling digunakan sebagai baseline awal namun terbukti memiliki kelemahan kritis:

1. Alokasi Buta Kapasitas

Tugas raksasa (40k-60k MI) kerap terlempar ke VM terkecil (800 MIPS), memicu bottleneck parah.

2. Pemborosan Sumber Daya

VM besar Surabaya (6.000 MIPS) terbiarkan menganggur (IDLE 14%), memperpanjang Makespan dan biaya sewa.

🐍 program_aoa_vs_random.py • schedule_random() 
def schedule_random(cloudlets: List[Cloudlet], vms: List[VM], seed: int) -> List[int]:
    """1. Random Scheduling (Baseline Minggu 3)"""
    rnd = random.Random(seed)
    # Memilih VM [0..9] secara acak seragam tanpa melihat beban maupun MIPS
    return [rnd.randint(0, len(vms) - 1) for _ in cloudlets]

# Analisis Dampak Inefisiensi pada Dataset 100 Cloudlets:
# - VM 8 (Yogya 800 MIPS) menerima beban 60.780 MI -> Bottleneck eksekusi 75.9 detik!
# - VM 0 (Surabaya 6.000 MIPS) hanya kebagian beban ringan -> IDLE terbuang 14.8% waktu
# - Makespan membengkak ke 444.29s dan Indeks Ketimpangan Beban (LBI) melonjak ke 2.20
INTI PEMBELAJARAN POS 2
Tanpa kesadaran kapasitas MIPS dan antrean aktif, penjadwalan acak membuat server kecil kewalahan sementara server supercepat menganggur.

POS 04 • BAGIAN 03 • MATEMATIKA AOA YANG BARU

Mengapa Memilih AOA? Keunggulan 4 Operator Aritmatika

AOA (Abualigah et al., 2021) mengoptimalkan alokasi dengan dua fase matematis yang adaptif (dilambangkan dengan Jurus Listrik ⚡ untuk Eksplorasi & Jurus Api 🔥 untuk Eksploitasi):

🐍 program_aoa_vs_random.py • AOAScheduler.optimize() 
# 1. Math Optimizer Accelerated (MOA): Penentu transisi Eksplorasi -> Eksploitasi
moa = 0.2 + t * ((0.9 - 0.2) / self.max_iter)

# 2. Math Optimizer Probability (MOP): Koefisien presisi penyesuaian posisi
mop = 1.0 - (math.pow(t, 1.0 / self.alpha) / math.pow(self.max_iter, 1.0 / self.alpha))

for i in range(self.pop_size):
    new_ind = list(population[i])
    for j in range(self.num_tasks):
        r1, r2, r3 = self.rnd.random(), self.rnd.random(), self.rnd.random()
        perturb = (ub - lb) * self.mu_rate * (self.rnd.random() - 0.5) * 2.0

        if r1 > moa:
            # ⚡ FASE EKSPLORASI LUAS: Operator Pembagian (/) dan Perkalian (*)
            val = best_schedule[j] / (mop + 1e-5) * (1.0 + perturb * 0.1) if r2 < 0.5                   else best_schedule[j] * mop * (1.0 + perturb * 0.1)
        else:
            # 🔥 FASE EKSPLOITASI INTENSIF: Operator Pengurangan (-) dan Penambahan (+)
            val = best_schedule[j] - mop * perturb if r3 < 0.5                   else best_schedule[j] + mop * perturb

        # Continuous-to-Discrete Mapping: Bulatkan ke Indeks VM valid [0..9]
        new_ind[j] = max(0, min(9, int(round(val))))

    # Update Best Solution bila Makespan jadwal baru lebih singkat
    res = evaluate_schedule(new_ind, self.cloudlets, self.vms)
    if res.makespan < best_fitness:
        best_fitness = res.makespan
        best_schedule = list(new_ind)
POS 05 • BAGIAN 04 • DEPLOYMENT REAL-WORLD

Bagaimana Program AOA Diterapkan & Dievaluasi?

Di lingkungan produksi nyata, AOA bekerja di layer Cloud Controller Dispatcher untuk mengevaluasi fitness jadwal:

🐍 program_aoa_vs_random.py • evaluate_schedule() 
def evaluate_schedule(schedule: List[int], cloudlets: List[Cloudlet], vms: List[VM]) -> EvalResult:
    # 1. Kelompokkan tugas ke VM masing-masing sesuai indeks jadwal
    vm_tasks = {vm.id: [] for vm in vms}
    for task_idx, vm_id in enumerate(schedule):
        vm_tasks[vm_id].append(cloudlets[task_idx])

    # 2. Makespan = Waktu penyelesaian VM paling lambat (T_max)
    makespan = max(vm_finish_times.values())
    throughput = len(cloudlets) / makespan  # Tugas selesai per detik
    
    # 3. Load Balancing Index (LBI) = (Beban Maks - Beban Min) / Rata-rata Beban
    avg_busy = sum(vm_busy_times.values()) / len(vms)
    lbi = (max(vm_busy_times.values()) - min(vm_busy_times.values())) / avg_busy
    
    # 4. Total Biaya Sewa ($) = Komputasi CPU ($0.03/s) + Sewa Server + Transfer I/O
    total_cost = total_proc_cost + (makespan * 0.03 * len(vms) * 0.1) + total_tx_cost
    return EvalResult(makespan, throughput, avg_util, lbi, total_cost)
INTI PEMBELAJARAN POS 5
Target utama fungsi objektif AOA adalah meminimalkan Makespan (waktu selesai keseluruhan) yang secara otomatis menurunkan ketimpangan beban (LBI) dan menghemat biaya sewa server.

168 |     return EvalResult(makespan, throughput, avg_util, lbi, total_cost)

175 | def schedule_random(cloudlets: List[Cloudlet], vms: List[VM], seed: int) -> List[int]:
176 |     """1. Random Scheduling (Baseline Minggu 3)"""
177 |     rnd = random.Random(seed)
178 |     return [rnd.randint(0, len(vms) - 1) for _ in cloudlets]

181 | class AOAScheduler:
182 |     """2. Arithmetic Optimization Algorithm (AOA) - Abualigah et al. (2021)"""
183 |     def __init__(self, cloudlets: List[Cloudlet], vms: List[VM], pop_size: int = 30, max_iter: int = 50, seed: int = 42):
184 |         self.cloudlets = cloudlets
185 |         self.vms = vms
186 |         self.num_tasks = len(cloudlets)
187 |         self.num_vms = len(vms)
188 |         self.pop_size = pop_size
189 |         self.max_iter = max_iter
190 |         self.alpha = 5.0
191 |         self.mu_rate = 0.499
192 |         self.rnd = random.Random(seed)
193 | 
194 |     def optimize(self) -> Tuple[List[int], EvalResult]:
195 |         lb, ub = 0, self.num_vms - 1
196 | 
197 |         # 1. Inisialisasi Populasi Agen [pop_size x num_tasks]
198 |         population = [[self.rnd.randint(lb, ub) for _ in range(self.num_tasks)] for _ in range(self.pop_size)]
199 | 
200 |         best_schedule = population[0]
201 |         best_result = evaluate_schedule(best_schedule, self.cloudlets, self.vms)
202 |         best_fitness = best_result.makespan
203 | 
204 |         for ind in population:
205 |             res = evaluate_schedule(ind, self.cloudlets, self.vms)
206 |             if res.makespan < best_fitness:
207 |                 best_fitness = res.makespan
208 |                 best_schedule = list(ind)
209 |                 best_result = res
210 | 
211 |         # 2. Siklus Iterasi AOA
212 |         for t in range(1, self.max_iter + 1):
213 |             # Math Optimizer Accelerated (MOA)
214 |             moa = 0.2 + t * ((0.9 - 0.2) / self.max_iter)
215 | 
216 |             # Math Optimizer Probability (MOP)
217 |             mop = 1.0 - (math.pow(t, 1.0 / self.alpha) / math.pow(self.max_iter, 1.0 / self.alpha))
218 | 
219 |             for i in range(self.pop_size):
220 |                 new_ind = list(population[i])
221 | 
222 |                 for j in range(self.num_tasks):
223 |                     r1, r2, r3 = self.rnd.random(), self.rnd.random(), self.rnd.random()
224 |                     perturb = (ub - lb) * self.mu_rate * (self.rnd.random() - 0.5) * 2.0
225 | 
226 |                     if r1 > moa:
227 |                         # Fase Eksplorasi: Pembagian (/) dan Perkalian (*)
228 |                         if r2 < 0.5:
229 |                             val = best_schedule[j] / (mop + 1e-5) * (1.0 + perturb * 0.1)
230 |                         else:
231 |                             val = best_schedule[j] * mop * (1.0 + perturb * 0.1)
232 |                     else:
233 |                         # Fase Eksploitasi: Pengurangan (-) dan Penambahan (+)
234 |                         if r3 < 0.5:
235 |                             val = best_schedule[j] - mop * perturb
236 |                         else:
237 |                             val = best_schedule[j] + mop * perturb
238 | 
239 |                     vm_idx = int(round(val))
240 |                     vm_idx = max(lb, min(ub, vm_idx))
241 |                     new_ind[j] = vm_idx
242 | 
243 |                 res = evaluate_schedule(new_ind, self.cloudlets, self.vms)
244 |                 if res.makespan < best_fitness:
245 |                     best_fitness = res.makespan
246 |                     best_schedule = list(new_ind)
247 |                     best_result = res
248 | 
249 |                 population[i] = new_ind
250 | 
251 |         return best_schedule, best_result
